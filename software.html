Build a routine you can return to.

A personal learning organizer built in Python. The desktop application has a bilingual PyQt6 interface; its separate command-line interface is English-only.

DESKTOP / 1.1.0

StudyFlow Desktop

For learners who prefer a dedicated workspace and local learning notes.

  • Arabic and English with RTL support
  • Guided plans, practice, reflections and spaced review
  • Local SQLite plans and JSON backup export
  • Reschedule remaining sessions while retaining progress

Windows x64 build exists locally. It is unsigned and is not offered as a public download here yet.

COMMAND LINE / 1.0.0

StudyFlow CLI

For terminal users who want the planning engine without the desktop interface.

  • English-only interface and guided content
  • Create plans, view today and record session reflections
  • Local data with import, export and replanning commands
studyflow templates
studyflow plan create --template python --preview
studyflow today
studyflow progress

Commands are documentation examples and are not executed in this page. Public executable downloads are not available yet.
