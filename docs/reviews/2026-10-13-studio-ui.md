# Playground UI refresh — 2026-10-13

## Presentation

- A compact task selector replaces the seven hero buttons. The selected task still shows its purpose, three start steps and a direct tool link. The choice survives language switching.
- The hero has shorter copy, a clear route to My Work, quieter metadata and a dark quick-launch surface in both themes.
- Tool cards use aligned icon/category/favorite headers, concise descriptions, smaller metadata and consistent full-width open actions. All seven original tools remain available.
- Favorite controls use native SVG stars with specific accessible names and pressed states. Optional saving is still required and explained in the disabled label.
- Learning, development and security icons have distinct tint accents. Light mode keeps strong dark actions and readable copy.
- Shared headers, buttons, panels and spacing are more consistent across the ten pages. Web tools and installed programs remain distinct.
- Desktop pointer hover, keyboard focus, RTL arrows and gentle hero entrance motion are supported. Touch hover does not shift cards, and reduced-motion preferences disable the new motion.

## Checks
